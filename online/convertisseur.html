Convertisseur de sauvegarde

Convertissez une sauvegarde prise sous une ancienne version (v1, v2) au format de la v3. Tout se passe dans votre navigateur : le fichier n'est envoyé nulle part.

v1 · v2 → v3 100 % local HTTPS
Choisir la sauvegarde

Sélectionnez le fichier .backup téléchargé depuis la page Firmware de votre appareil.

Le fichier est lu sur place, dans cet onglet : rien n'est enregistré, rien ne part sur internet.
Ce que fait la conversion

La sauvegarde est relue exactement comme votre appareil l'aurait relue, puis réécrite dans le format de la v3 : une ligne par élément, chaque valeur portant son nom. Équipements, groupes, pièces, plannings, réglages, réseau et radio sont conservés.

Important
Une sauvegarde contient les adresses radio et les codes tournants de vos équipements — dans le nouveau format, ils se lisent en clair. Quiconque possède ce fichier peut piloter vos équipements : ne le publiez jamais (forum, capture d'écran, dépôt public).

Le fichier converti se restaure depuis la page Système › Appareil de la v3.
