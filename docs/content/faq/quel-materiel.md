# De quel matériel ai-je besoin&nbsp;?

Pour fabriquer soi-même un appareil, il suffit de&nbsp;:

- **1 module ESP32**&nbsp;;
- **1 module émetteur-récepteur CC1101**&nbsp;;
- **8 câbles Dupont** (femelle/femelle).

Aucun fer à souder ni connaissance avancée en développement ne sont requis. La
page [Composants](../commun/composants.md) liste les cartes compatibles et
le brochage de chacune.

Vous préférez un appareil déjà assemblé et préconfiguré&nbsp;? Voir les
[boîtiers officiels](../boitiers/index.md).

Ensuite, le firmware s'écrit sur la puce depuis le navigateur, avec
l'[Installateur web](../outils/installateur-web.md).
