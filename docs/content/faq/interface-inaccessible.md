# L'interface ne répond plus

Plusieurs portes de secours existent, de la plus légère à la plus complète&nbsp;:

1. **Le point d'accès de secours**&nbsp;: sans Wi-Fi ou sans réseau, l'appareil
   ouvre son propre point d'accès, à rejoindre pour le reconfigurer.
2. **Le mode Récupération**&nbsp;: trois coupures d'alimentation rapides, chacune
   dans les 5 secondes qui suivent le démarrage précédent. Il répare un appareil
   dont l'interface pose problème sans dépendre de ce qui est cassé. Voir
   [Mode Récupération](../v3/recuperation.md).
3. **Les journaux du port série**&nbsp;: quand plus rien ne répond par le réseau,
   le câble USB reste le seul témoin. Voir
   [Journaux du port série](../commun/journaux-port-serie.md).
4. **Un nouveau flash**, avec l'[Installateur web](../outils/installateur-web.md),
   puis la [restauration d'une sauvegarde](../v3/firmware/restaurer.md).
