# Boîtiers officiels

Les boîtiers ESPSomfy-RTS livrés déjà assemblés et préconfigurés, en édition
Wi-Fi ou Ethernet. Choisissez la fiche qui correspond à la version du firmware
installée sur votre boîtier&nbsp;: elle est affichée dans l'interface, sous
**Système → Firmware**.
