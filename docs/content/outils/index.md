# Outils en ligne

Des outils qui fonctionnent directement dans le navigateur, sans rien installer.

<div class="grid cards" markdown>

-   :material-usb-flash-drive:{ .lg .middle } **[Installateur web ESPSomfy-RTS](installateur-web.md)**

    ---

    Écrit le firmware sur l'ESP32 par le câble USB, depuis le navigateur. Il intègre son propre
    moniteur série : voir [les journaux série](installateur-web.md#journaux).

-   :material-lifebuoy:{ .lg .middle } **[Installateur de secours : web.esphome.io](installateur-esphome.md)**

    ---

    Une seconde voie pour écrire le firmware, si l'installateur d'ESPSomfy-RTS ne
    fonctionne pas pour vous. Un outil tiers, décrit pas à pas. Son moniteur série se lit
    avec la page [Journaux du port série](journaux-port-serie.md).

-   :material-map-marker:{ .lg .middle } **[Géolocalisation](geolocalisation.md)**

    ---

    Trouve les coordonnées GPS de votre domicile et les transmet à l'appareil,
    pour les programmations au lever et au coucher du soleil.

</div>
