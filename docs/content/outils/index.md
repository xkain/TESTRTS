# Outils en ligne

Des outils qui fonctionnent directement dans le navigateur, sans rien installer.

<div class="grid cards" markdown>

-   :material-usb-flash-drive:{ .lg .middle } **[Installateur web](installateur-web.md)**

    ---

    Écrit le firmware sur l'ESP32 par le câble USB, depuis le navigateur.

-   :material-map-marker:{ .lg .middle } **[Géolocalisation](geolocalisation.md)**

    ---

    Trouve les coordonnées GPS de votre domicile et les transmet à l'appareil,
    pour les programmations au lever et au coucher du soleil.

</div>
