Installateur web

Installez ESPSomfy-RTS sur votre appareil, changez de version et lisez ses journaux, sans rien installer sur votre ordinateur.

Connectez votre appareil

Reliez votre ESP32 à un port USB de cet ordinateur, puis choisissez-le dans la fenêtre que votre navigateur va ouvrir. Tout se déroule ici : aucune donnée ne quitte votre ordinateur, et le firmware part de cette page vers l'appareil sans passer par un serveur.

Important
L'installation par navigateur nécessite un navigateur compatible Web Serial (Chrome, Edge ou Opera) sur ordinateur, avec cette page chargée en HTTPS.
Aucun port dans la liste ?
Trois causes, dans l'ordre de fréquence : un câble USB de charge, sans fil de données ; le pilote du convertisseur USB-série absent (CP2102 ou CH340 selon la carte) ; ou l'appareil branché après l'ouverture de la fenêtre. Changez de câble, installez le pilote, puis réessayez.

Modèle sélectionné :

La mémoire de l'appareil est entièrement effacée avant l'écriture. Au premier démarrage, un assistant intégré vous guidera pour la configuration, langue de l'interface comprise.

Important
Pour ce modèle : maintenez le bouton poussoir situé sous le boîtier enfoncé avant de cliquer sur « Installer ». Relâchez-le une fois l'effacement terminé et l'écriture du firmware commencée. Une fois l'installation terminée, débranchez puis rebranchez le boîtier pour qu'il quitte le mode flash.

Ça ne fonctionne pas ? Essayez l'installateur alternatif web.esphome.io
