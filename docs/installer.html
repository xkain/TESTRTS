ESPSomfy-RTS Flashez votre ESP32 directement depuis ce navigateur.
L'installation par navigateur nécessite un navigateur compatible Web Serial (Chrome, Edge ou Firefox récent) sur ordinateur, avec cette page chargée en HTTPS.

Disposez-vous d'un boîtier officiel ESPSomfy-RTS ?

Le parcours s'adapte selon votre réponse.

Choisissez votre modèle

Le modèle est indiqué sur l'étiquette sous le boîtier.

Tout est prêt !

Modèle sélectionné :

Tout est préconfiguré pour votre boîtier (brochage GPIO, configuration radio) : l'interface sera automatiquement accessible dès la mise sous tension. Vous pourrez choisir la langue de l'interface dans l'assistant de premier démarrage, directement sur l'appareil.

Important
Pour ce modèle : maintenez le bouton poussoir situé sous le boîtier enfoncé avant de cliquer sur « Installer ». Relâchez-le une fois l'effacement terminé et l'écriture du firmware commencée. Une fois l'installation terminée, débranchez puis rebranchez le boîtier pour qu'il quitte le mode flash.
Important
Un effacement complet de la mémoire flash est effectué automatiquement avant l'installation. Le choix du port USB se fait dans la fenêtre native de votre navigateur au clic sur « Installer ».

Ça ne fonctionne pas ? Essayez l'installateur alternatif web.esphome.io

Choisissez votre carte

Le modèle est généralement indiqué sur la carte ou sa documentation.

Prêt à flasher

Modèle sélectionné :

Le flash efface entièrement la mémoire de votre ESP32 avant d'installer ESPSomfy-RTS. Au premier démarrage, un assistant intégré vous guidera pour la configuration, langue de l'interface comprise.

Important
Un effacement complet de la mémoire flash est effectué automatiquement avant l'installation. Le choix du port USB se fait dans la fenêtre native de votre navigateur au clic sur « Installer ».

Ça ne fonctionne pas ? Essayez l'installateur alternatif web.esphome.io

Sécurité et vie privée : Le flash s'effectue entièrement dans votre navigateur, en liaison directe avec votre appareil USB. Le firmware est téléchargé depuis les releases GitHub du projet ; aucune donnée n'est transmise à un autre tiers.
