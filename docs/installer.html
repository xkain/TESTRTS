🛠️ Autre carte ESP32 ?

Suivez les 3 étapes ci-dessous.

1Choisissez votre carte

Le modèle est généralement indiqué sur la carte ou sa documentation.

2Langue de l'appareil

Vous pourrez sélectionner {lang} dès le premier démarrage : le boîtier téléchargera automatiquement le pack de traduction correspondant.

3Flash USB

Choisissez d'abord une carte à l'étape 1.

⚠️ Un effacement complet de la mémoire flash est effectué automatiquement avant l'installation. Le choix du port USB se fait dans la fenêtre native de votre navigateur au clic sur « Installer ».

🔒
Sécurité et vie privée : Le flash s'effectue entièrement dans votre navigateur, en liaison directe avec votre appareil USB. Le firmware est téléchargé depuis les releases GitHub du projet ; aucune donnée n'est transmise à un autre tiers.
